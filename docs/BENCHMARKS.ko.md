## 측정 정의와 데이터

D window는 최초의 완전한 full-width cycle부터 첫 lane 완료 직전까지이며16 cycle 이상·1초 이상입니다. Acceptance는 동일 window에서 배포 코드가 유지한 accepted draft를 활성 lane당 제안7개로 나눈 값입니다. Anchor/bonus·비활성 padding은 제외하고 거부된 제안은 분모에 유지합니다. 종료 경계 cycle도 제외합니다.

TTFT는 제출부터 최초의 비어 있지 않은 SSE content까지이며 cohort·요청별 값을 보존합니다. Full-wave에는 대기·prefill·decode·완료가 포함됩니다. C는 제출 client 수이고 B/R은 관측값입니다. 조기 EOS를 유지하고 출력을 강제하지 않습니다. 표본 범위에는 작업별 차이가 포함되며 작은 n은 p99나 정밀한 신뢰구간이 아닙니다. Cap에 도달한 응답은 처리량 표본이며 patch·test 작업 완료를 뜻하지 않습니다.

Native tracked Metal, sample 기반 native process physical footprint, process-tree RSS는 합산할 수 없는 별도 지표입니다. 실행별 swap·pressure와 runtime headroom은 비공개 증거에 보존합니다.
